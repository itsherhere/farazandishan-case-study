# Recruiter Summary

**FarazAndishan** is a bilingual corporate and HR platform.

My work covered Next.js, React, TypeScript, responsive UI, Persian/English RTL-LTR support, Sanity CMS, GraphQL integration, protected application flows, SEO, and production build quality.

The strongest engineering aspect of the project is the separation of responsibilities:

- public content is CMS-backed
- protected functionality uses the client's existing backend
- server-side Next.js code acts as the integration boundary
- UI components consume normalized application data

For an Ausbildung application, this project demonstrates practical experience with:

- real client requirements
- integrating with an existing backend
- reusable frontend architecture
- multilingual interfaces
- larger application structure
- CI and release checks
- technical documentation
